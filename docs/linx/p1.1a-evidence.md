## 覆盖点

- T3 `SqlitePersistence.layerMemory` 与 Linx 客户端同时存在，互不覆盖；Linx 表不含 T3 orchestration 表。
- `linx.sqlite` 使用 `linx_migrations`；迁移重复执行只记录一次。
- 资源按内容哈希落盘，权限 0600；路径穿越、符号链接、哈希不一致被拒绝。
- 快照内容稳定排序，哈希可复算；同 revision 不同内容冲突；篡改后读取失败。
- 绑定与 Outbox 同事务提交；同 key/同 hash 恢复；command id 冲突回滚，不留半条绑定。
